# تقرير الفحص والإصلاح — صديقي قلم
التاريخ: 2026-11-03

## التسليم
هذا هو المشروع المعدل بصيغة ZIP، وليس APK. احتُفظ بكل الملفات الأصلية الضرورية، وأضيف مشروع Android أصلي قابل للبناء وأدلة الفحص. لم تُحذف أي ملفات أصلية (569 ملفاً). جميع التسجيلات والأيقونات الأصلية مطابقة بايتاً ببايت.

## نتائج فعلية
- بناء Android: نجحت assembleDebug وbundleRelease وlintDebug. السجل الكامل مرفق.
- compileSdk وtargetSdk: 36. Capacitor 8.6.0، Node 22+، JDK 21. الحد الأدنى لأندرويد أصبح API 24 (Android 7)، وهو حد Capacitor 8؛ لا تدعم هذه النسخة الأجهزة الأقدم.
- المسارات التي شملها المسح الآلي: 327.
- محاولات النقر الآلي المسجلة: 2662. نقرات تعذر إكمالها: 0؛ تفاصيلها في fixed-sweep.json. ليست هذه شهادة بتغطية كل حالة ممكنة لكل زر.
- أخطاء JavaScript غير المعالجة أثناء المسح: 0. أخطاء console: 0.
- سيناريوهات وظيفية مستقلة: 15/15، ومنها إنشاء طفل، إنشاء/فتح رمز الأهل، الإجابات الخاطئة والمراجعة، حفظ الإعدادات، تنزيل نسخة احتياطية، رفض استعادة تالفة دون تغيير البيانات، وإدخال رسم فعلي بالمؤشر.
- فحص ثوابت 1700 سؤال مولد آلياً؛ هذا فحص بنيوي للخيارات والإجابة، وليس مراجعة تربوية/شرعية لكل نص.
- دون اتصال: نجح الوصول إلى 563 مورداً بعد تجهيز التخزين، بما فيها التسجيلات، ونجحت إعادة التحميل وفتح الخصوصية وطلبات الصوت الجزئية 206. الملف المفقود يعيد 504 ولا يعيد HTML مكان الصوت.
- أحجام العرض: 320×568, 360×640, 390×844, 412×915, 768×1024, 1024×768. تفاصيل عدد الصفحات لكل حجم محفوظة. مجموع الأحجام ذات تجاوز عرض مرصود: 0.
- npm audit: لا ثغرات معروفة في شجرة الاعتماديات المقفلة وقت الفحص؛ ليس ضماناً أمنياً دائماً.
- Android Lint للتطبيق: 0 أخطاء، 33 تحذيرات. التحذيرات المتبقية ظاهرة وليست مخفية؛ تشمل تحديثات اختيارية، تثبيت الاتجاه كما في البناء الأصلي، وأيقونات/موارد قالب Capacitor. بعض تحذيرات مكتبات الطرف الثالث وbaseline الخاصة بها موجودة في السجل.

## الإصلاحات الأساسية
1. إزالة طلب bridge.min.js المفقود؛ جسر Capacitor يحقن إضافاته الأصلية بنفسه.
2. حذف كود التنقل غير القابل للوصول ومتغيرات ثبت عدم استخدامها، دون حذف شاشات أو وظائف.
3. تخزين جميع المحتويات دون اتصال، وإصدارات cache مشتقة من بصمة الموارد، وعزل cache التطبيق وعدم حذف cache التطبيقات الأخرى، ودعم نطاقات الصوت.
4. إصلاح استعادة النسخ الاحتياطية والتحقق قبل الكتابة، مع منع المفاتيح الخطرة والأنواع غير الصالحة؛ حماية الملف الحالي عند الرفض.
5. حذف كل البيانات يمسح أيضاً الإعدادات ومفاتيح الأهل ونسخ الاسترداد، ولا يحذف بيانات التطبيقات الأخرى على الأصل نفسه.
6. ربط الموسيقى وإعداد سرعتها/القراءة بحالة الصوت الفعلية؛ تحسين تسلسل النطق وإغلاق مؤقتات/أحداث لوحة الرمز.
7. حفظ الامتحان الخاص لا يسقط الأسئلة الناقصة بصمت، ولا يكرر مستمع الاختيار بعد إعادة الرسم.
8. معالجة فئة حديقة غير معروفة بدلاً من انهيار الصفحة.
9. إصلاح تجاوز الإعدادات والحديقة وأزرار القصص على الشاشات الضيقة، وإضافة دعم تقليل الحركة وتركيز لوحة المفاتيح للنوافذ.
10. تضمين App وFilesystem وShare وTextToSpeech لنظام Android، وتصدير النسخة الاحتياطية الأصلية من cache عبر المشاركة، مع تضييق FileProvider.
11. تعطيل النسخ السحابي/نقل بيانات نظام Android تلقائياً، وتوضيح الاستثناء الخاص بالمشاركة اليدوية في الخصوصية.
12. تثبيت الاعتماديات بملف lock، وإصلاح .gitignore كي لا يستبعد مشروع Android الضروري، وتحديث CI لبناء قابل للإعادة.

## حدود لا يجوز تجاوزها في وصف النتيجة
- لا يتوفر جهاز Android فعلي أو محاكي عامل في هذه البيئة. لم تُختبر لمسياً على أجهزة حقيقية: الرجوع الأصلي، المشاركة الأصلية، اختيار الملفات، محركات النطق المحلية، النظام في الخلفية، وتعامل WebView مع لوحة المفاتيح وقطع الشاشة. تم بناء هذه الأجزاء لكن بناءها ليس اختبار تشغيلها.
- الصوتيات الأصلية محفوظة واختُبرت قابلية جلبها؛ لم تُراجع جميع التسجيلات سمعياً ولم تُدقّق مطابقة كل نص ديني/تعليمي مع تسجيله.
- لم تُقَس ذاكرة/طاقة/حرارة التطبيق على أجهزة منخفضة المواصفات؛ لا يوجد ضمان خلو من كل عطل أو ادعاء مراجعة بشرية لكل حرف.
- مخرجات release اختُبرت دون توقيع إنتاجي. لا يتضمن ZIP مفاتيح أو شهادات أو ملفات APK/AAB. يلزم مفتاح رفع صحيح ورقم versionCode أعلى من المنشور عند التحديث، واستكمال صفحة المتجر وData safety وFamilies والتحقق من الحقوق وبيانات التواصل، واختبار Google Play الداخلي/Pre-launch قبل اعتماد النشر.
- رمز الأهل حاجز إشراف وليس تشفيراً قوياً لبيانات الأطفال. JSON المصدّر غير مشفر؛ يلزم حفظه بأمان.

## إعادة البناء
npm ci
npm run build
cd android
./gradlew assembleDebug bundleRelease lintDebug

الأدوات المطلوبة: Node 22 أو أحدث، JDK 21، Android SDK platform 36 وBuild Tools 36.0.0. عرّف ANDROID_HOME أو أنشئ local.properties على جهازك. ملف local.properties الخاص ببيئة الفحص مستبعد عمداً، وكذلك node_modules وملفات البناء.
عند تعديل www شغّل npm run build لتحديث بصمة cache ونسخ الموارد الأصلية.
